# ARSIA

ARSIA is a responsive road-safety analytics interface prototype. It contains six dashboard views built with static HTML, CSS, and JavaScript, using mock data only.

## Pages

- Overview
- Trends
- Severity
- Map
- Basic Units
- Data Quality

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static web server.

## Collaboration workflow

1. Create a branch for each change.
2. Open a pull request for review.
3. Merge approved changes into `main`.
4. Vercel automatically deploys `main` to production and creates previews for other branches.

## Data

This prototype currently uses mock data and does not connect to the assignment database or API.
