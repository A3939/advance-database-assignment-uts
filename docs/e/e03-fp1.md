# E03 — FP1 SQL and deployment contract

Owner: Role E / Aditya

## Contract

- Function: e.fp1(jsonb)
- Return type: text
- Implementation: SHA-256 of PostgreSQL canonical jsonb text
- PostgreSQL target: 16.x, UTF-8, UTC
- Input: normalized manifest fingerprint payload only; provenance/runtime fields are excluded by FrozenManifest.fingerprint_input()
- Output: exactly 64 lowercase hexadecimal characters
- Execution: caller-owned transaction; no commit/rollback/close by FP1

## Deployment

1. Apply the SQL file sql/e/fp1.sql after the team migrations.
2. Verify pg_proc reports schema e, function fp1, one jsonb argument and text return type.
3. Verify EXECUTE is granted to arsia_loader.
4. Record server_version_num, server_encoding, client_encoding and TimeZone.
5. Run the independent FP1 tests and retain the SQL/deployment evidence.

The existing B adapter in src/arsia_ingest/fingerprint.py already enforces these environment and signature checks. This E delivery supplies the missing real SQL implementation and deployment instructions.
